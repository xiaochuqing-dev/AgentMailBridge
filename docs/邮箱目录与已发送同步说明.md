# 邮箱目录与已发送同步说明

v1.7.1 使用 Provider-neutral `mailboxes` 事实保存稳定 mailbox_id、account_id、原始名、显示名、层级、delimiter、SPECIAL-USE 角色、启用/同步状态和 UIDVALIDITY。目录可表示 Inbox、Sent、Archive、Drafts、Spam/Junk、Trash、Important/Starred、Gmail Label 和自定义目录。

优先使用 IMAP SPECIAL-USE 或 Gmail Label metadata。Provider 未给出角色时只能使用可审计候选，不能只靠英文目录名。默认同步 Inbox 与 Sent；Spam、Trash 和自定义目录需要用户明确启用。`all` 权限包含以后发现并启用的目录，`selected` 不自动扩张；停用或移除目录后旧 mailbox_id 也不能继续访问。

每个目录拥有独立 checkpoint、尝试事实和 membership 快照。IMAP 使用 UIDVALIDITY、UIDNEXT、last_uid、重叠 UID 和 `BODY.PEEK[]`；Gmail API 使用消息实际 labelIds 和重叠时间窗口。完整成功快照才可把旧 membership 标为 server absent；失败或 partial 不清零 checkpoint。UIDVALIDITY 变化只重置受影响目录，不改变历史 package 身份。同步不删除、移动或标记远端邮件。

Sent 同步覆盖网页端、手机、其他客户端和 AgentMailBridge 发出的邮件。本地 outbound 回流优先使用账号一致加 raw Hash 精确匹配，其次使用唯一 Message-ID 与 From、To/Cc、Subject、内容/附件指纹和有界时间窗口。多候选保持 ambiguous；没有本地请求的邮件作为 external outbound 归档。

一封邮件可同时拥有多条 `mail_package_mailboxes`。目录移动或 Label 变化只更新 membership 与 `currently_present`，不改变 direction，也不删除本地 package。详细模型见《邮件事实与目录归属设计》《Sent对账与重复识别》和《同步Checkpoint与UIDVALIDITY恢复》。
