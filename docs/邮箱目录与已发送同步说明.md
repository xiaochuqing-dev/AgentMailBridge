# 邮箱目录与已发送同步说明

v1.7.0 使用 Provider-neutral `mailboxes` 事实保存稳定 mailbox_id、account_id、原始名、显示名、层级、delimiter、SPECIAL-USE 角色、启用/同步状态和 UIDVALIDITY。目录可表示 Inbox、Sent、Archive、Drafts、Spam/Junk、Trash、Important/Starred、Gmail Label 和自定义目录。

优先使用 IMAP SPECIAL-USE 或 Gmail Label metadata。Provider 未给出角色时只能使用可审计候选，不能只靠英文目录名。默认同步 Inbox 与 Sent；Spam、Trash 和自定义目录需要用户明确启用。`all` 权限包含以后发现并启用的目录，`selected` 不自动扩张；停用或移除目录后旧 mailbox_id 也不能继续访问。

每个目录拥有独立 checkpoint。IMAP 使用 UIDVALIDITY、UIDNEXT、last_uid、重叠 UID 和 `BODY.PEEK[]`；Gmail API 使用 label 查询和重叠时间窗口。UIDVALIDITY 变化只重置受影响目录的 checkpoint，不改变历史 package 身份。同步不删除、移动或标记远端邮件。

Sent 同步覆盖网页端、手机、其他客户端和 AgentMailBridge 发出的邮件。本地 outbound 回流时综合 Message-ID、Provider/server ID、account_id、RFC Header、内容/附件指纹和发送时间窗口映射已有 package，既防止重复，也避免把实际不同的邮件错误合并。
