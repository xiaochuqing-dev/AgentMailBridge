# 发件事实与线程关系说明

每次通用发件先持久化 send request，再取得 lease 并构建一次 MIME。固定 Message-ID、MIME bytes 和 SHA-256 进入请求与 attempt 事实；传给 SMTP 的同一 bytes 用于 outbound `raw.eml`，不能发送一份、归档另一份。Bcc 地址只进入 SMTP envelope 和私有事实，不出现在公开 MIME Header。

成功或结果不确定的发送保存 direction evidence、account_id、Client、发件模式、是否用户确认、From/To/Cc/Bcc、正文、附件、Message-ID、In-Reply-To、References、reply_to_package_id、forward_from_package_id、请求幂等键、Provider 结果和 Hash。目录 membership 独立保存。事实包原子发布；SMTP 已接受但发布失败时记录 `sent_archive_failed` 和恢复信息，不自动重发。

线程关系只使用确定性证据：Message-ID、In-Reply-To、References、Gmail thread id、Provider conversation id、reply_to_package_id 和 forward_from_package_id。事实层返回按时间排序的 inbound/outbound 往来，不使用主题相似度或内置 AI 聚类。Sent 回流映射成功后补充服务器 mailbox/UID 事实，但不创建第二个 package。
