# Agent 权限理念说明

AgentMailBridge 保护的是秘密和用户授权边界，而不是削弱正常邮件能力。用户明确授权后，Agent 可以读取任何获准账号、目录、年份和资源，也可以使用任意获准发件账号向任意合法地址新建、回复、回复全部或转发，并使用多个收件人和多个附件。

普通权限分为读取开关、读取账号范围、邮箱目录范围、发件开关、发件账号范围、发送前确认/自主发送和本地附件目录范围。范围使用动态 `all` 或显式 `selected`；旧 Client 和新发现对象不会在 selected 模式下自动扩权。暂停、撤销、账号停用和目录停用立即生效。

密码、授权码、OAuth Token、Client token、Credential Manager 值和其他 MCP/API secret 永远不返回 Agent。发送服务只在内部按 credential_ref 获取秘密。响应、错误、审计、GUI 预览、备份展示、报告和 Git 都必须通过结构化脱敏。

产品不增加固定收件人、联系人或域名白名单，不限制某一年、单收件人或单附件。兼容 `submit_result` 的固定 owner 是旧工具自身语义，不是通用发件限制。产品不内置 AI、草稿、自动回复、定时发送、远程 Web API 或 Agent 编排。
