# 历史邮件导入说明

“导入历史邮件”用于把 AgentMailBridge 接入前的邮件建立为正式本地 Mail Package，不替代普通增量收件，也不修改远端邮件。

账号页提供最近 30 天、最近 1 年、任意自然年、跨年范围、全部历史、自定义时间和暂不导入。v1.7.0 可同时限定多个属于该账号且已启用的 mailbox_id；取消后的恢复继续使用原目录集合。长范围自动拆成连续季度分段，并复用 Gmail API 或共享 IMAP 业务层和统一归档。

界面和 `history_import_runs` 持久保存运行 ID、账号、预设、起止时间、当前/总分段、扫描、匹配、保存、重复、规则跳过、失败、截断、取消和错误状态。取消只停止后续扫描，已完成的邮件包保留；以后继续时从未完成分段开始，正式归档去重防止重复邮件包。

导入与自动收件共用账号级进程内锁和跨进程锁，但不推进普通增量 checkpoint。单封邮件或附件失败不会阻断后续邮件；partial 保留成功结果，truncated 明确记录安全扫描上限。Gmail API 继续只使用 `gmail.readonly`；IMAP 使用 `BODY.PEEK[]`，不标记已读、不移动、不删除。

真实验收以 2024 年为固定范围。在至少一个已配置 QQ 或 163 账号执行真实导入，记录脱敏账号 ID、分段、数量和 Hash 结论，从成功归档对象中自动选择一封验证正文、raw.eml、资源、account ownership 和 SHA-256。私人正文、附件和完整邮箱地址不得进入报告或 Git。

稳定状态与错误包括 `completed`、`no_changes`、`partial`（可带 `truncated` 标记）、`cancelled`、`failed`，以及 `history_import_cancelled`、`history_import_partial`、`history_import_truncated`、`history_import_failed` 和 `history_import_not_found`。
